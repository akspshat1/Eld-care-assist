# 高齢者見守りアシスタント

*[English version](README.md)*

ひとり暮らしの高齢者のためのAIコンパニオンと、その方を気にかけるご家族のための
ダッシュボードです。

音声で会話し、毎日の体調チェックインを声だけで行い、表情と「声の調子」から気分を
読み取り、服薬を管理して飲むまで声かけを続けます。そして何より重要なのは、
**異変に気づいたとき、数秒以内に生身の人間へ知らせる**ことです。

すべてブラウザで動作します。日本語と英語に対応しています。

**AI は [OrcaRouter](https://orcarouter.ai) を利用しています。**

```bash
pip install -r eld_care_assist/requirements.txt
cp .env.example .env          # APIキーを記入します
python run.py
```

<http://127.0.0.1:8100> が開きます。

---

## なぜ作ったのか

82歳の方がひとりで暮らしています。娘さんは車で2時間の距離。ヘルパーの訪問は
週に2回です。

その合間、眠れたのか、食べたのか、薬を飲んだのか、火曜日以降だれかと話したのか、
誰にも分かりません。娘さんが異変を知るのは、それがすでに緊急事態になってからです。

このアプリは、その空白を埋めます。毎日「話しかける」ことで — フォームは埋めなくても、
人は**話す**からです — その会話を、ご家族が30秒で読めるものに変えます。

## 3つの使い方

| モード | 対象 | できること |
|---|---|---|
| **本人** | ご本人 | 大きなボタン、やさしい配色、専門用語なし。会話・チェックイン・お薬。**ロックなし** |
| **ケアチーム** | ご家族、介護者、看護師 | 上記すべてに加えて、スコア・推移・アラート・レポート・連絡先。**PIN で保護** |
| **ハロー・ロボ** | 画面を使えない/使いたくない方 | 画面なし。棚の上に置いたまま、名前を呼ばれるのを待ちます |

ご本人の画面は**意図的に一切ロックしません**。PIN を忘れたせいで、お薬の予定が
見られなくなるようなことがあってはならないからです。

## 話しかけるだけ

**「ハロー・ロボ」**と呼ぶと目を覚まします。そのあとは —

| こう言うと | こうなります |
|---|---|
| 「今日のお薬は何？」 | 今日飲むお薬と時間を読み上げます |
| 「薬を飲んだよ」 | 服用済みとして記録します。ボタン操作は不要です |
| 「チェックインをしたい」 | 毎日の体調チェックインを会話で行います |
| 「娘に電話して」 | 「娘」として登録された連絡先に発信します |
| 「健二さんに電話して」 | 健二さんに発信します |
| 「胸が痛い」 | **数秒以内にご家族へ緊急通知** |
| 「助けて」 | **数秒以内にご家族へ緊急通知** |
| 「今日はさびしいな」 | そのまま話し相手になります |
| 「おやすみ」 | 待機状態に戻ります |

しばらく静かなときは自分から眠りに戻ります。頼まれた以上に長く「聞き耳を立てる」
ことがないようにするためです。

## 機能

### 毎日の体調チェックイン — 音声で

中心となる日課です。質問は6つ — **睡眠・食欲・痛み・体力・気分・寂しさ** — に
加えて「何か心配なことはありますか」。

**🎙 話して答える**を押すと、本物の会話になります。ひとつ質問し、聞き、受け止めて、
次を尋ねる。ボタンも「録音開始」も発信音待ちもなく、ゆっくり話す方が途中で
切られることもありません。

終わると、回答がフォームに記入された状態で表示されます。何がどう理解されたかを、
介護者が確認し、**修正できる**ためです。ボタンをタップして答える方法も常に使えます。

その後、任意で**写真**とご本人の**肉声**を記録します。これらすべてが次のかたちに
なります。

- **100点満点の健康スコア**
- 平易な言葉のまとめ
- 具体的な気がかりな点
- 医療行為ではない、ささやかな提案

### おしゃべり

孤独は、誰もコードにしない症状です。これは目的のない会話 — AIから先に話しかけ、
待ち、応え、相手が話し始めた瞬間に話すのをやめます。

文字を打つ、マイクを1回タップする、あるいは**🎙 ハンズフリー会話**を押して
ただ話す。

話した回は保存され、あとから声の調子を確認できます。「会話を記録する」を押すと、
気分・要約・特筆事項が申し送りに書き込まれます。

### 表情と声から気分を読む

2つのことを、ノートPC上で読み取ります。

- **表情** — 平静・喜び・悲しみ・怒り・驚き・恐れ・嫌悪・軽蔑
- **声** — 言葉ではなく「調子」から、怒り・喜び・平静・悲しみ

大事なのはラベルそのものではありません。**話す内容と声の調子は、しばしば食い違う**
ということです。疲れた平板な声で言う「大丈夫です」こそ、高齢者ケアで最も有用な
サインであり、テキストだけのチャットボットが捨ててしまうものです。

### 服薬

**登録：**処方箋を撮影するか、テキストを貼り付けます。薬剤名・用量・時間・期間が
自動で読み取られます。「1日2回7日分、その後1日1回3週間」といった現実的で厄介な
書き方にも対応します。日本語の処方箋も読めます。

**服用：**時間になると、選択中の言語で声に出して知らせます。

> 「アムロジピン5ミリグラムのお時間です。飲まれたら『飲んだ』とおっしゃってください。」

**「飲んだ」**と言えば、何にも触れずに記録されます。

返事がない場合は5分おきに、**最大5回まで**繰り返します。予定時刻から30分を過ぎたら
声かけをやめ、未服用として記録します。いつまでも催促する機器はコンセントを抜かれて
しまいますし、静かに記録された未服用のほうが、延々と問い続けるより役に立つからです。

未服用は家族ダッシュボードに表示されます。

### 緊急アラート

すべてのモードの、すべての会話が、その場で**20種類の異変**と照合されます。

**緊急** — 胸の痛み、呼吸困難、脳卒中の兆候、転倒、頭部外傷、出血、窒息、
強いめまい、激しい痛み、しびれ、突然の視力低下、過量服薬、自傷、助けを求める声。

**注意** — 食べていない、眠れていない、痛みの悪化、著しい気分の落ち込み、発熱、嘔吐。

該当すると、**数秒以内**に生身の人へ通知が届きます — Discord、Slack、メール、SMS。
ご本人の名前、**実際に話された言葉**、時刻、深刻度が含まれます。緊急は赤色で
チャンネルに通知、注意は琥珀色です。

むやみに騒ぎません。「胸は痛くない」「いえ、めまいはしません」ではアラートは
上がりません。

アラートは常に記録され、アプリ内に表示されます。通知先が未設定の場合は、送信した
ふりをせず、はっきりそう表示します。

### ガーディアンモード

助けを求める声のための、常時待受です。

待機中は何も保持しません。聞こえた音声は確認のうえ**ただちに破棄されます** —
保存も送信も記録もされません。助けを求める声があったときだけ、アラートが飛びます。

「転倒してタブレットに手が届かなかったら？」への答えがこれです。

### 家族ダッシュボード

「今日の母はどう？」に30秒で答えるための画面です。単独アプリとしても、メインアプリ内の
タブとしても使えます。

- **これまでの様子** — 14日間の推移。アラートのしきい値を線として重ねて描くので、
  **なぜ**フラグが立ったのかが目で分かります
- **注意が必要なこと** — 低いスコア、未服用、いつもと違う静けさ
- **タイムライン** — チェックイン、会話、服薬、アラートを時系列で
- **ダイジェスト** — ご家族が実際に読める、短いまとめ
- **連絡先** — ご家族や介護者を電話番号・メールとともに登録。そのままアラートの
  宛先になり、ご本人が声で電話をかけられる相手にもなります

しきい値は選べます。何点以下を「低い」とするか、何時間の沈黙を「異常」とするか、
何回の未服用で知らせるか。

### 申し送りレポート

一日を**これまでの様子 / 気をつけたいこと / 対応が必要なこと**にまとめます。
介護者の申し送りが実際に取っている形です。チェックイン、会話、服薬、アラートを
集約し、CSV に書き出せます。

### 覚えています

会話をまたいで覚えています。膝がずっと痛むこと、日曜にお孫さんが来ること。
毎朝ご自分の人生を紹介し直さなくて済むようにするためです。

あえて小さく保っているので、負担になりません。

### 日英バイリンガル

トグルひとつで切り替わり、しかも表示だけではありません。

- 画面表示
- AIが**返答する**言語
- 音声を**書き起こす**言語
- 服薬の音声リマインド
- チェックインの質問と要約
- アラートの文面

### プライバシーとセキュリティ

弱い立場にある方の健康データは、丁重に扱われるべきです。

- **音声記録は暗号化**して保存されます
- **臨床画面は PIN で保護**。画面上で隠すだけでなくサーバー側で拒否し、
  ロック画面は背後をぼかすので透かして読むこともできません
- **セッションは8時間**で失効します
- **音声記録は既定で30日後に自動削除**されます
- **健康記録の閲覧は記録**されます
- **秘密情報はすべて gitignore された1ファイルに。**コードにも Git にも入りません

### デモ用時計

右下の調整できる時計で、時刻を直接入力するか1時間ずつ動かせます。

すべてのタイムスタンプ、日付の境界、服薬の予定時刻、リマインドがこれに従うため、
朝10時に夜のお薬のリマインドを実演できます。リセットで実時刻に戻ります。

## セットアップ

### 1. インストール

```bash
pip install -r eld_care_assist/requirements.txt
```

Python 3.10 以上。`run.py` を実行するものと同じインタープリタを使ってください。

### 2. APIキーを入れる

```bash
cp .env.example .env
```

`.env.example` に説明つきで一覧があります。gitignore 済みなので、キーが
コミットされることはありません。

### 3. 気分読み取りモデルの取得（任意）

```bash
cd Face_rec  && python download_models.py
cd voice_rec && python download_models.py
```

なくても他の機能はすべて動作し、気分の読み取りだけ「モデルがありません」と
表示されます。

### 4. 起動

```bash
python run.py                # メインアプリ＋家族ダッシュボード、ブラウザが開きます
python run.py --all          # 単独アプリ3つも起動
python run.py --only care    # 1つだけ: care|family|face|voice|meds
python run.py --check        # 起動せずに構成を確認
python run.py --list         # アプリとポートの一覧
```

`--check` は、起動前に何が足りないかを正確に教えてくれます。

| アプリ | ポート | 既定で起動 |
|---|---|---|
| 高齢者見守りアシスタント | 8100 | ✅ |
| 家族ダッシュボード | 8300 | ✅ |
| 表情の気分（単独） | 8000 | `--all` |
| 声の気分（単独） | 8001 | `--all` |
| 服薬管理（単独） | 8002 | `--all` |

## 設定

すべてリポジトリ直下の `.env` にあり、全アプリが共有します。全項目は
`.env.example` にあります。よく使うものは次のとおりです。

| 設定 | 既定値 | 役割 |
|---|---|---|
| `ORCAROUTER_API_KEY` | — | AI を動かします |
| `CARE_PIN` | 未設定 | ケアチーム画面の PIN。未設定ならロックなし |
| `ALERT_WEBHOOK_URL` | — | 緊急通知の送り先 — Discord または Slack |
| `SMTP_*` | — | メールで通知する場合 |
| `TWILIO_*` | — | SMS で通知する場合 |
| `AUDIO_RETENTION_DAYS` | `30` | N日後に音声を削除（0で保持） |
| `FAM_LOW_WELLBEING` | `40` | この値以下で注意扱い |
| `FAM_QUIET_HOURS` | `36` | 何時間の沈黙で家族へ知らせるか |
| `FAM_MISSED_DOSES` | `2` | 連続何回の未服用で家族へ知らせるか |

Discord 通知の設定は1分ほどです。サーバー設定 → 連携サービス → ウェブフック →
新しいウェブフック → URLをコピー → `ALERT_WEBHOOK_URL` に貼り付け。アプリ内に
**テスト通知を送る**ボタンがあります。

## 困ったときは

**ハンズフリー音声が聞き取ってくれない** — マイクを許可し、タブがミュートに
なっていないか確認してください。ブラウザは操作なしに音声を開始しないため、まず
ページ上のボタンをクリックしてください。

**日本語が表示されるのに読み上げられない** — OS に日本語音声が入っていません。
Windows：設定 → 時刻と言語 → 音声認識 → 音声を管理する → 日本語を追加。

**起動時に何か足りない** — `python run.py --check` を実行してください。何が
不足しているかと、その解決コマンドが表示されます。

**更新したのに画面が古いまま** — `Ctrl+F5` でスーパーリロードしてください。

**ポートが使用中** — `run.py` は中途半端に起動せず中止します。他のプロセスを
止めるか、`--only` を使ってください。
